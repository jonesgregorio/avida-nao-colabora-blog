1. código da `main`;
2. `kind-lucid-clarke/mnt/outputs/avida-nao-colabora-blog/README.md`;
3. testes automatizados;
4. documentação técnica mais recente dentro de `kind-lucid-clarke/mnt/outputs/avida-nao-colabora-blog/docs/`.
