# Fase 19 — Validação de browser

Checkpoint operacional criado exclusivamente para disparar a suíte Browser E2E sobre a `main` já contendo a Fase 18.

Objetivo desta validação:

- confirmar jornada autenticada da Ideia 1;
- validar desktop 1440 px;
- validar mobile 390 px;
- validar telas estreitas 320 px;
- verificar overflow horizontal;
- verificar navegação central;
- verificar acessibilidade automatizada;
- não alterar comportamento, banco, planos, Stripe, autenticação ou rollout.

Este arquivo não possui efeito em runtime.
